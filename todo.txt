
План организации работы с документацией для проекта boba-artifacts
===================================================================

ЭТАП 1: Структура — создать скелет документации
-------------------------------------------------
1. Создать директорию docs/ с подкаталогами:
   - docs/architecture/   — архитектурные решения (ADR), схемы взаимодействия boba ↔ boba-artifacts
   - docs/deployment/     — деплоймент (открытый/закрытый контур, air-gap перенос, nginx-конфиг)
   - docs/configuration/  — подробное описание config.toml, .env, prompts/, pip.conf
   - docs/tools/          — документация per tool-плагин (files, chromadb, confluence, html, postgres-fts)
   - docs/troubleshooting/ — FAQ и типичные проблемы (сборка, запуск, подключение LLM)
   - docs/prompts/        — гайд по настройке and prompt-инжинирингу (как писать промпты в local/prompts/)

2. Создать индексную страницу docs/README.md — карта документации с ссылками на разделы

ЭТАП 2: Миграция — перенести разрозненную информацию в docs/
-------------------------------------------------------------
3. Вынести заметки из local/README.md (Ollama API) в docs/deployment/ollama-setup.md
   — оформить как гайд по настройке LLM-бэкенда: установка моделей, подключение, примеры запросов
4. Дополнить README.md проекта:
   — добавить ссылку на docs/ для детальной документации
   — убрать дублирование с docs/ (операционные details → в docs/, README оставить как quickstart)
5. Удалить или заменить sandbox/docs.txt на осмысленный тестовый контент

ЭТАП 3: Наполнение — написать недостающую документацию
-------------------------------------------------------
6. docs/architecture/overview.md — диаграмма компонент: monorepo boba/packages/* ↔ boba-artifacts, роли (core/infra/tools/agents), поток данных
7. docs/architecture/build-pipeline.md — пошаговое описание цепочки: Dockerfile.base → wheels → Dockerfile → images → docker-compose
8. docs/configuration/env-reference.md — полный справочник переменных окружения (BOBA_*) с типами, дефолтами, примерами
9. docs/configuration/config-toml-reference.md — полный справочник config.toml: [agent], [cli], [chainlit], [tool.*]
10. docs/tools/*.md — per-plugin документация: что делает плагин, как включить/выключить, зависимости, примеры использования
11. docs/prompts/prompt-guide.md — рекомендации по написанию промптов, примеры, best practices для ассистента boba
12. docs/troubleshooting/faq.md — типовые ошибки сборки, проблемы с LLM, docker-сети, volumes

ЭТАП 4: Интеграция с AI-ассистентом
------------------------------------
13. Обновить local/prompts/10-files.md — добавить в инструкции ассистента paths для поиска в docs/
14. (Опционально) Настроить ChromaDB-индексацию docs/ для семантического поиска через tool.chromadb
    — включить [tool.chromadb] enable = true в config.toml
    — добавить docs/ как source для индексации

ЭТАП 5: Процесс поддержания актуальности
-----------------------------------------

16. Добавить CHANGELOG.md для отслеживания значимых изменений
17. Добавить docs-чеклист в PR/review-процесс (если есть CI/CD)
